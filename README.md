# 🚀 DevMaster Pro — Full-Stack Java & AI Quiz Platform

An interactive, responsive, and topic-wise Computer Science quiz application built using **HTML5, CSS3, JavaScript (ES6+), and Bootstrap 5**. This platform offers practice modules across Full-Stack Java Development, Cloud & DevOps, Git/GitHub, and Generative AI concepts.

---

## ✨ Features

- 📚 **Multi-Subject Curriculum:** Covers HTML5, CSS3, JavaScript, Bootstrap, Core Java, Spring Boot, Cloud/DevOps, Git/GitHub, and Generative AI.
- 🎯 **Topic-Wise Practice:** Categorized quizzes with dedicated question banks.
- ⏱️ **Live Countdown Timer:** 30-second timer per question with auto-submission.
- 💡 **Instant Explanations:** Detailed answer breakdowns provided right after selecting an option.
- 🔖 **Bookmark System:** Save challenging questions for later review.
- 📊 **Performance Analytics:** Score summary with accuracy percentage and custom performance feedback.
- 🎨 **Modern UI/UX:** Styled with a Navy Blue & Cream color scheme, custom glassmorphism effects, and smooth CSS animations.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6+)
- **Framework:** Bootstrap 5.3
- **Icons & Fonts:** FontAwesome 6, Google Fonts (Poppins)
